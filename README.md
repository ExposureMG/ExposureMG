# ExposureMG

Nothing particularly serious here, just personal and hobby projects, mostly Xbox 360 or Web.

### GX Collection

* [gxBuild](https://github.com/ExposureMG/gxBuild) - My attempt at a modernized Xbox 360 image builder
* [J-Runner-with-gxBuild](https://github.com/ExposureMG/J-Runner-with-gxBuild) - J-Runner fork using gxBuild
* [J-Runner-with-gxBuild-Files](https://github.com/ExposureMG/J-Runner-with-gxBuild-Files) - Support files for J-Runner-with-gxBuild
* [ExCrypt-gx](https://github.com/ExposureMG/ExCrypt-gx) - ExCrypt soft fork with multi-platform/compiler changes, Depended on by gxBuild
* [Sonus-gx](https://github.com/ExposureMG/Sonus-gx) - Vibecoded standalone Sonus360 binary builder in Rust

### XboxOCD

* [xboxocd](https://github.com/ExposureMG/xboxocd) - Solution for Pi Pico JTAG flashing, using OpenOCD 0.11 and [jeanthom]()'s dirtyjtag patches. Made useless by a xsvftool update
* [J-Runner-with-gxBuild-and-xboxocd](https://github.com/ExposureMG/J-Runner-with-gxBuild) - For-fun fork of J-Runner gxBuild using XboxOCD for as much as possible
