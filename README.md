### gxBuild - [Source](https://github.com/ExposureMG/gxBuild)

Will make public soon

Start-to-finish xeBuild clone in rust, with 2026 updates (Glitch3, XDKBuild, Signature Patching, FFI, Developer API)


### J-Runner with gxBuild - [Source](https://github.com/ExposureMG/J-Runner-with-gxBuild), [Support Files](https://github.com/ExposureMG/J-Runner-with-gxBuild-Files)

Big J-Runner fork offloading everything possible onto gxBuild, with a bag of UI updates, a gxRemapper implementation, and PICF2SPI.

### Other gx Projects

* [ExCrypt-gx](https://github.com/ExposureMG/ExCrypt-gx) - ExCrypt soft fork with multi-platform/compiler changes, Depended on by gxBuild
* [Sonus-gx](https://github.com/ExposureMG/Sonus-gx) - Vibecoded standalone Sonus360 binary builder in Rust

### Hardware Flashing

* [gxRemapper](https://github.com/ExposureMG/gxRemapper) - On the fly bad block remapper
* [PICFLASH v2](https://github.com/ExposureMG/PICFLASH) - Modernized fork of the PICFLASH firmware with bulk reads and writes
* [PICF2SPI](https://github.com/ExposureMG/PICF2SPI) - Standalone DLL to interact with PICFLASH v2
* [FTDI2SPI](https://github.com/ExposureMG/FTDI2SPI) - Fork of [Octal450's FTDI2SPI](https://github.com/Octal450/FTDI2SPI) implementing gxRemapper

### XboxOCD

* [xboxocd](https://github.com/ExposureMG/xboxocd) - Solution for Pi Pico JTAG flashing, using OpenOCD 0.11 and [jeanthom's DirtyJTAG patches](https://github.com/jeanthom/openocd-dirtyjtag). Made useless by a xsvftool update 😂
* [J-Runner-with-gxBuild-and-xboxocd](https://github.com/ExposureMG/J-Runner-with-gxBuild) - For-fun fork of J-Runner gxBuild using XboxOCD for as much as possible
